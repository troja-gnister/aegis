# Aegis Phase 1 Secure Platform Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the legacy C tree with a deployable Django/React/PostgreSQL foundation where users authenticate through the same-origin gateway and can see only root shells granted to them.

**Architecture:** One Django modular monolith supplies session authentication, administration, root authorization, audit, durable jobs, and health APIs. React provides a dark mobile shell, while unprivileged Nginx fronts the API and static build; PostgreSQL coordinates state and separate process roles run from one backend image. Deployment-declared mount slots and per-role credentials, volumes, and networks establish the security boundaries needed by later phases without implementing file enumeration or mutation yet.

**Tech Stack:** Python 3.13, Django 5.2 LTS, Django REST Framework 3.16, psycopg 3, uv, PostgreSQL 18, React 19.2, TypeScript, Vite 8, Node.js 24 LTS, npm, Vitest, Testing Library, Playwright, unprivileged Nginx, optional Caddy, Docker Compose, pytest, Hypothesis, Ruff, and mypy.

**Spec:** [`docs/superpowers/specs/2026-08-31-aegis-platform-rewrite-design.md`](../specs/2026-08-31-aegis-platform-rewrite-design.md)

- Browser authentication uses revocable server-side Django sessions and CSRF cookies. Never store bearer tokens in browser storage.

- Root grants are additive across direct user and Django-group grants. There are no deny rules, and platform-superuser status never implies product data access.
- The web service receives no original-root mount. Gateway/indexer/media receive read-only roots; only operations may receive a writable root.
- All containers run unprivileged, drop all capabilities, use read-only application filesystems, have no Docker socket, and receive only role-scoped secrets and volumes.
- PostgreSQL is the initial durable queue and coordination store. Do not add Redis.
- Use UUIDs for externally visible application objects. Never return a host/container root path from an API.
- Use real PostgreSQL for integration tests. SQLite is not an accepted substitute.
- The default UI is deep slate with indigo/cyan accents, visible focus, reduced-motion support, and 44-by-44 CSS-pixel minimum interactive targets.
- Every behavior change follows red-green-refactor. Run the named failing test before implementation and the named passing test afterward.

## Phase 1 Acceptance Gate

The phase is complete only when all of the following are demonstrated through the production-like Compose stack:

1. an installation can bootstrap an administrator from file-backed secrets;
2. a normal user can obtain CSRF state, log in, refresh the browser, and retain a revocable session;
3. direct and group grants expose only the authorized active root shells;
4. a platform administrator with no root grant sees no product roots;
5. unauthenticated, cross-root, stale-epoch, and direct protected-location requests fail;
6. root mount slots are deployment-declared, alias-checked, and consistent across mounted roles;
7. workers publish heartbeats but cannot mutate immutable operation intents or use another role's database privileges;
8. login, logout, failed login, administration, and grant changes create append-only audit records;
9. the dark mobile shell works at the defined phone viewport and clears authenticated state on logout/back navigation;
10. backend, frontend, browser, Compose, container-boundary, and migration checks pass from clean locked installs.

- [ ] **Step 2: Implement strict typed configuration**

```python
# backend/aegis/config.py
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
import stat
from typing import Literal, Mapping, overload
from urllib.parse import urlparse


class ConfigurationError(RuntimeError):
    pass


@overload
def read_secret(
    environ: Mapping[str, str],
    name: str,
    *,
    production: bool,
    required: Literal[True] = True,
) -> str: ...


@overload
def read_secret(
    environ: Mapping[str, str],
    name: str,
    *,
    production: bool,
    required: Literal[False],
) -> str | None: ...


def read_secret(
    environ: Mapping[str, str],
    name: str,
    *,
    production: bool,
    required: bool = True,
) -> str | None:
    file_name = f"{name}_FILE"
    if production and name in environ:
        raise ConfigurationError(f"{name} must be file-backed in production")
    if file_name in environ:
        path = Path(environ[file_name])
        info = path.lstat()
        if not stat.S_ISREG(info.st_mode) or path.is_symlink():
            raise ConfigurationError(f"{file_name} must name a regular file")
        if stat.S_IMODE(info.st_mode) & 0o077:
            raise ConfigurationError(f"{file_name} must have mode 0600")
        if info.st_size > 4096:
            raise ConfigurationError(f"{file_name} exceeds 4096 bytes")
        value = path.read_text(encoding="utf-8")
        if value.endswith("\n"):
            value = value[:-1]
        if not value:
            raise ConfigurationError(f"{file_name} is empty")
        return value
    value = environ.get(name, "")
    if not value and required:
        raise ConfigurationError(f"{file_name} is required")
    return value or None


@dataclass(frozen=True)
class RuntimeConfig:
    environment: str
    public_url: str
    allowed_hosts: tuple[str, ...]
    django_secret_key: str
    db_name: str
    db_user: str
    db_password: str
    db_host: str
    db_port: int
    secure_cookies: bool
    trust_proxy_headers: bool

    @classmethod
    def from_environ(cls, environ: Mapping[str, str]) -> "RuntimeConfig":
        environment = environ.get("AEGIS_ENV", "development")
        production = environment == "production"
        public_url = environ.get("AEGIS_PUBLIC_URL", "http://localhost:8080")
        parsed = urlparse(public_url)
        if parsed.scheme not in {"http", "https"} or not parsed.hostname:
            raise ConfigurationError("AEGIS_PUBLIC_URL must be an absolute HTTP(S) URL")
        hosts = tuple(
            host.strip()
            for host in environ.get("AEGIS_ALLOWED_HOSTS", parsed.hostname).split(",")
            if host.strip()
        )
        return cls(
            environment=environment,
            public_url=public_url,
            allowed_hosts=hosts,
            django_secret_key=read_secret(
                environ, "AEGIS_DJANGO_SECRET_KEY", production=production
            ),
            db_name=environ.get("AEGIS_DB_NAME", "aegis"),
            db_user=environ.get("AEGIS_DB_USER", "aegis_web"),
            db_password=read_secret(environ, "AEGIS_DB_PASSWORD", production=production),
            db_host=environ.get("AEGIS_DB_HOST", "127.0.0.1"),
            db_port=int(environ.get("AEGIS_DB_PORT", "5432")),
            secure_cookies=parsed.scheme == "https",
            trust_proxy_headers=environ.get("AEGIS_TRUST_PROXY_HEADERS", "false") == "true",
```

Accept only request IDs matching `^[A-Za-z0-9_-]{8,64}$`; otherwise generate a 128-bit hex value. Bind and reset the context variable in a `try/finally`, return the value on every response, and never trust a forwarding header outside the configured proxy hop.

The JSON formatter emits timestamp, level, logger, message, request ID, actor ID when known, event name, and safe metadata. REQUEST_ID = re.compile(r"^[A-Za-z0-9_-]{8,64}$")


```python
class RequestContextMiddleware:
    def __call__(self, request: HttpRequest) -> HttpResponse:
        supplied = request.headers.get("X-Request-ID", "")
        request_id = supplied if REQUEST_ID.fullmatch(supplied) else secrets.token_hex(16)
        token = request_id_var.set(request_id)
        request.request_id = request_id
        try:
            response = self.get_response(request)
            response.headers["X-Request-ID"] = request_id
            return response
        finally:
            request_id_var.reset(token)
```

- [ ] **Step 5: Add runtime manifest parsing without path disclosure**

`MountManifest.load()` checks owner/mode, schema version, duplicate slot IDs/identities, fixed container paths, and configured digest. It exposes `get(slot_id: str) -> ManifestSlot | None`, where `ManifestSlot` contains expected/observed identity and mode but has no host-source field. Exceptions and logs name only the slot ID.

```python
# backend/aegis_apps/roots/manifest.py
@dataclass(frozen=True, slots=True)
class ManifestSlot:
    slot_id: str
    container_path: PurePosixPath
    mode: Literal["read_only", "read_write"]
    expected_identity: str
    filesystem_id: int
    root_inode: int


@dataclass(frozen=True, slots=True)
class MountManifest:
    digest: str
    slots: Mapping[str, ManifestSlot]

    @classmethod
    def load(cls, path: Path, expected_digest: str) -> "MountManifest":
        info = path.lstat()
        if not stat.S_ISREG(info.st_mode) or path.is_symlink():
            raise ManifestError("mount manifest is not a regular file")
        if stat.S_IMODE(info.st_mode) & 0o022:
            raise ManifestError("mount manifest is writable by group or world")
        raw = path.read_bytes()
        digest = hashlib.sha256(raw).hexdigest()
        if not secrets.compare_digest(digest, expected_digest):
            raise ManifestError("mount manifest digest mismatch")
        payload = json.loads(raw)
        if payload.get("version") != 1 or not isinstance(payload.get("slots"), list):
            raise ManifestError("unsupported mount manifest schema")
        slots: dict[str, ManifestSlot] = {}
        identities: set[str] = set()
        for item in payload["slots"]:
            slot = parse_manifest_slot(item)
            if slot.slot_id in slots or slot.expected_identity in identities:
                raise ManifestError("duplicate mount slot identity")
            expected_path = PurePosixPath("/srv/aegis/roots") / slot.slot_id
            if slot.container_path != expected_path:
                raise ManifestError(f"invalid container path for slot {slot.slot_id}")
            slots[slot.slot_id] = slot
            identities.add(slot.expected_identity)
        return cls(digest=digest, slots=MappingProxyType(slots))

    def get(self, slot_id: str) -> ManifestSlot | None:
        return self.slots.get(slot_id)
```

`parse_manifest_slot()` performs the slot-ID, type, integer-range, identity-prefix, and mode validation from Step 1 and constructs `ManifestSlot`; do not add any other field to it.

- [ ] **Step 5: Make operation intent immutable in application code**

`create_operation()` canonicalizes its bounded JSON, computes SHA-256 request hash, records current authorization epochs, and creates its first job in one transaction. Override `Operation.save()` to permit inserts only and `delete()` to reject deletion. Prevent edits to a job's operation, role, kind, payload, priority, or max-attempt fields after insert.
```python
IMMUTABLE_JOB_FIELDS = frozenset(
    {"operation_id", "target_role", "kind", "payload", "priority", "max_attempts"}
)


def create_operation(*, actor: User, request_id: str, kind: str, intent: Mapping[str, object]) -> Operation:
    canonical = json.dumps(intent, sort_keys=True, separators=(",", ":"), ensure_ascii=True)
    if len(canonical.encode()) > 16_384:
        raise ValueError("operation intent exceeds 16384 bytes")
    hash_input = b"\x00".join((str(actor.id).encode(), kind.encode(), canonical.encode()))
    with transaction.atomic():
        snapshot = capture_authorization_snapshot(actor=actor, intent=intent)
        operation = Operation.objects.create(
            actor=actor,
            request_id=request_id,
            kind=kind,
            request_hash=hashlib.sha256(hash_input).digest(),
            intent=json.loads(canonical),
            authorization_snapshot=snapshot,
        )
        Job.objects.create(
            operation=operation,
            target_role=target_role_for(kind),
            kind=kind,
            payload=json.loads(canonical),
            state=JobState.QUEUED,
            available_at=timezone.now(),
        )
    return operation
```

- [ ] **Step 2: Implement the same-origin API client**

Allow only relative `/api/v1/` URLs, set `credentials: "same-origin"`, request JSON explicitly, and attach `X-CSRFToken` only to non-safe methods. Reject redirects to another origin. Limit parsed error bodies and map unknown failures to a stable user-safe problem; detailed server bodies never enter the DOM.

Do not create a bearer-token type or persistence key. Keep the CSRF value in memory, refresh it through `/auth/csrf`, and retry exactly once only for the server's explicit stale-CSRF response.

```typescript
// frontend/src/api/http.ts
type ApiRequestInit = Omit<RequestInit, "body" | "credentials" | "redirect"> & {
  body?: unknown;
  csrfToken?: string;
};

const SAFE_METHODS = new Set(["GET", "HEAD", "OPTIONS"]);

export async function apiRequest<T>(path: string, init: ApiRequestInit = {}): Promise<T> {
  if (!path.startsWith("/api/v1/") || path.startsWith("//")) {
    throw new Error("API path must be same-origin and versioned");
  }
  const {body, csrfToken, ...requestInit} = init;
  const headers = new Headers(requestInit.headers);
  headers.set("Accept", "application/json");
  if (body !== undefined) headers.set("Content-Type", "application/json");
  if (!SAFE_METHODS.has(requestInit.method ?? "GET") && csrfToken) {
    headers.set("X-CSRFToken", csrfToken);
  }
  const response = await fetch(path, {
    ...requestInit,
    headers,
    credentials: "same-origin",
    redirect: "error",
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  if (!response.ok) throw await parseBoundedProblem(response);
  return response.status === 204 ? (undefined as T) : ((await response.json()) as T);
}
```

`parseBoundedProblem()` reads at most 16 KiB from a cloned response stream and accepts only the stable `type`, `title`, `status`, and `retryAfterSeconds` fields.
